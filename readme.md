# Price Watch

Price Watch is a simple Chrome extension for tracking product prices without signing up or sending your data anywhere. If you are shopping online and want to know when a price drops, this extension lets you add a product to your watchlist and keep an eye on it from your browser.

### Install (chrome)
1. Install from [Chrome Web store](https://chromewebstore.google.com/detail/price-watch/eaihpgepobgdiamflkgeidhbpgljbohi)
2. Click **Add to Chrome**
3. and use it on any e commerce site


### Features

Price Watch lets you save products you care about, monitor their price changes in the background, and get notified the moment a drop happens. It works directly from your browser, keeps things simple, and helps you spot good deals without constantly checking the same page again and again.
